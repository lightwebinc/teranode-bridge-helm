{{- if not $c.mineTag }}

WARNING: config.mineTag is empty with the reverse path enabled. Blockchain
notifications carry no origin, so a block this cluster learned over libp2p BEFORE
the fabric delivered it looks locally produced and will be republished upward
with false attribution. Set config.mineTag to this cluster's
coinbase_arbitrary_text (e.g. /teranode1/).
{{- end }}
